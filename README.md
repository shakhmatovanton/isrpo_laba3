# Quick Commit

Плагин для Visual Studio Code для быстрого коммита текущего файла без переключения в терминал.

**Автор:** Шахматов Антон Юрьевич  
**Группа:** М3110  

## Возможности

### 1. `Quick Commit: commit current file`
- Коммитит **только текущий открытый файл**.
- Перед коммитом проверяет: открыт ли файл, является ли папка Git-репозиторием, настроены ли `user.name` и `user.email`.
- Если изменений нет — сообщает об этом и прерывает работу.
- Показывает `git diff` в панели Output для подтверждения.
- После коммита показывает короткий хэш и сообщение созданного коммита.
- Не затрагивает другие staged-файлы — они остаются в индексе.

### 2. `Quick Commit: Show History of Current File`
- Показывает последние **5 коммитов** текущего файла.
- Для каждого коммита отображает: хэш, автора, дату, сообщение.
- При выборе коммита открывает панель Output с подробностями (`git show --stat`).

## Горячие клавиши
- `Ctrl+Alt+C` (Windows/Linux) / `Cmd+Alt+C` (macOS) — вызвать коммит текущего файла.
